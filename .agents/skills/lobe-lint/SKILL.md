# Lobe Lint

> ESLint, Prettier, Stylelint, Commitlint, Remarklint and Semantic Release configs for LobeHub projects, plus a one-command setup CLI.

## Setup

- Package: `@lobehub/lint`
- Repository: https://github.com/lobehub/lobe-lint
- Docs: https://lint.lobehub.com/

## Workflow

1. Pick candidates from the index below. Groups follow the source folder, which usually maps to the import entry.
2. Fetch the linked reference page before writing code. It holds the documented usage, props and API tables.
3. Only use props, variants and imports that the reference page documents. Follow its Docs link to see live demos.

The page index with outlines is at https://lint.lobehub.com/llms.txt.

### packages

#### CLI

- [create-lobe-lint](https://lint.lobehub.com/skills/packages/create-lobe-lint.md) — CLI that detects your project and generates LobeHub lint configs, ignore files, git hooks and VSCode settings.

#### Configs

- [ESLint Config](https://lint.lobehub.com/skills/packages/eslint-config.md) — ESLint flat config for JavaScript, TypeScript and React projects, built from one defineConfig() factory.
- [Prettier Config](https://lint.lobehub.com/skills/packages/prettier-config.md) — Prettier config for LobeHub projects, with shell, package.json and JSON sorting plugins.
- [Stylelint Config](https://lint.lobehub.com/skills/packages/stylelint-config.md) — Stylelint config for CSS and Less, with property ordering and logical properties.
- [Commitlint Config](https://lint.lobehub.com/skills/packages/commitlint-config.md) — Commitlint config for gitmoji-style conventional commit messages.
- [Remarklint Config](https://lint.lobehub.com/skills/packages/remarklint-config.md) — Remark config that lints and formats Markdown, with GFM, frontmatter, TOC generation and CJK spacing.
- [Semantic Release Config](https://lint.lobehub.com/skills/packages/semantic-release-config.md) — Semantic Release config that turns gitmoji commits into versions, changelogs and releases.
- [Oxlint Config](https://lint.lobehub.com/skills/packages/oxlint-config.md) — The @lobehub/eslint-config rule set for Oxlint, without TypeScript or ESLint installed.

#### Meta

- [Lint Meta Package](https://lint.lobehub.com/skills/packages/lint.md) — @lobehub/lint re-exports every LobeHub lint config from a single package.
